# Deploying Weyvo (Render + Supabase, free tiers)

Code goes GitHub → Render. Data lives in Supabase. Supabase never connects to GitHub.

## 1. Supabase (done once)

1. New project, region **Southeast Asia (Singapore)**. Save the database password in a password manager.
2. Storage → New bucket `trip-photos`, **Public off**.
3. **Connect** (top bar) → **Session pooler**. It shows a URI like
   `postgresql://postgres.abcdxyz:[YOUR-PASSWORD]@aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres`
   Split it into three Render values:
   - `DATABASE_URL` = `jdbc:postgresql://aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres?sslmode=require`
     (the host and port from the URI, with `jdbc:` in front; no user or password inside it)
   - `DATABASE_USER` = `postgres.abcdxyz` (the part before the `:`)
   - `DATABASE_PASSWORD` = the database password
4. Project Settings → API Keys: copy the **Project URL** and the **service_role** key (Legacy API keys tab; secret).

Tables are created by the API itself on first start.

## 2. Render

1. New → **Blueprint** → this repo. Render reads `render.yaml` and creates `weyvo-api` and `weyvo-web`.
2. Paste the values it asks for: the three database values, `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`,
   `RESEND_API_KEY`, `MAIL_FROM` (`Weyvo <onboarding@resend.dev>` until a domain is verified),
   `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET` (test keys), `RAZORPAY_WEBHOOK_SECRET` (any long random string).
   `APP_JWT_SECRET` is generated by Render.
3. Apply. If Render had to rename a service (name taken), update the `/api` rewrite, `APP_URL` and
   `APP_CORS_ORIGINS` in `render.yaml` to the real addresses.

## 3. After the first deploy

1. Sign up on the live site, then in Supabase → SQL Editor:
   `UPDATE users SET is_admin = true WHERE username = '<you>';`
2. Open `https://weyvo-web.onrender.com/api/admin/request-info`. `clientIp` must be your own public IP
   (compare with any "what is my IP" site). It's read from `X-Forwarded-For`, skipping
   `APP_CLIENT_IP_TRUSTED_HOPS` (3) addresses Render's proxies add on the right. If Render changes its
   proxies and the IP is wrong, adjust that number.
3. Razorpay (test mode) → Webhooks → `https://weyvo-web.onrender.com/api/billing/webhook`, the same secret,
   event `payment.captured`.
4. cron-job.org: open `https://weyvo-web.onrender.com/api/places` every 10 minutes (keeps the free API awake
   and the Supabase project from pausing).

## Notes

- Free API sleeps after 15 idle minutes; the first visit after that waits about a minute.
- The API refuses to start in production with unsafe settings (dev session key, non-HTTPS cookie,
  localhost CORS, local photo storage) and says which one in the Render logs.
- Resend's test sender only delivers to your own address. Verify a domain before inviting testers.
